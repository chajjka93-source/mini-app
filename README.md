# Сайт Марины Чайка — chaika-bot.ru

Основной адрес: https://chaika-bot.ru (также открывается с www). Резервная копия на GitHub Pages: https://chajjka93-source.github.io/mini-app/. Сайт открывается и как Telegram Mini App через MChaika_bot.

## Где стоит и как разворачивается

- **Домен и хостинг:** Рег.ру, тариф «Хост-Лайт», сервер server277.hosting.red.ru. Домен chaika-bot.ru оплачен на год.
- **HTTPS:** сертификат Let's Encrypt выпускается на стороне Рег.ру, на момент записи действует до 7 февраля 2027. Запросы по http автоматически переходят на https.
- **Тип проекта:** статический сайт (HTML, CSS, картинки), сборки нет. В корень сайта на хостинге кладутся index.html, privacy.html, offer.html, consent.html, premium.css, папка assets.
- **Выкладка:** актуальная ветка main скачивается из репозитория, файлы загружаются на хостинг через файловый менеджер Рег.ру (архивом) или по FTP. Логин и пароль FTP лежат в разделе «Ключи и данные» агента, в репозиторий они не попадают. Папку preview-natalia-k7x2 и cloudflare/ на хостинг не заливать.
- **Проверка после выкладки:** открыть https://chaika-bot.ru, убедиться, что адрес http переходит на https, и отправить тестовую заявку из формы.

## Формы

Обе формы (квиз и контакты) отправляют JSON POST-запросом на https://form-service-chajjka.msk1.amvera.tech/. Это сервис form-service (Node) на Amvera, Москва-1, репозиторий chajjka93-source/form-service. Он проверяет поля и пересылает заявку владельцу в Telegram, успех подтверждается только после ответа Telegram. Форма разбора запрашивает контакт для ответа. При ошибке поля остаются заполненными, повторная отправка во время ожидания блокируется.

Старый обработчик на Cloudflare Workers (cloudflare/worker.mjs) больше не используется и оставлен как архив: его можно отключить. Секреты в репозиторий не кладутся.

## Что проверялось при создании

Проверены синтаксис встроенных скриптов, DOM-ссылки, отсутствие повторных ID, успешный и ошибочный ответы клиента, валидация и ответы обработчика с имитацией Telegram API. Реальную доставку нужно проверить тестовой заявкой с сайта. При ошибке поля остаются заполненными; повторная отправка во время ожидания блокируется.

# Telegram Mini App — Марина Чайка

Опубликованная версия: https://chajjka93-source.github.io/mini-app/

Статический лендинг открывается в Telegram через MChaika_bot и в обычном браузере. Этот репозиторий публикуется отдельно от my-lending-test на Vercel.

Обе формы отправляют JSON POST-запросом на https://mini-app-form.chajjka93.workers.dev/. Обработчик Cloudflare Workers вызывает Telegram Bot API sendMessage и доставляет заявку владельцу. Переход в мессенджер и копирование текста не требуются. Форма разбора запрашивает контакт для ответа.

Код обработчика: cloudflare/worker.mjs. В Cloudflare настроены секреты BOT_TOKEN и CHAT_ID; их значения не должны попадать в репозиторий. Владелец должен запустить бота командой /start. Обработчик принимает браузерные запросы с origin https://chajjka93-source.github.io, проверяет поля и подтверждает успех только после ответа Telegram. CORS не заменяет защиту от автоматического спама. Перед повторным развёртыванием обновляйте этот файл в редакторе Cloudflare.

Проверены синтаксис встроенных скриптов, DOM-ссылки, отсутствие повторных ID, успешный и ошибочный ответы клиента, валидация и ответы обработчика с имитацией Telegram API. Реальную доставку нужно проверить тестовой заявкой с сайта. При ошибке поля остаются заполненными; повторная отправка во время ожидания блокируется.

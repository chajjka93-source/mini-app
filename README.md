# Telegram Mini App — Марина Чайка

Опубликованная версия: https://chajjka93-source.github.io/mini-app/

Статический лендинг открывается в Telegram через MChaika_bot и в обычном браузере. Этот репозиторий публикуется отдельно от my-lending-test на Vercel.

После квиза или контактной формы кнопка «Продолжить в Telegram» открывает @chajjka с полным текстом в параметре `text`, закодированным через `encodeURIComponent`. Внутри Mini App существующий обработчик передаёт ссылку в `Telegram.WebApp.openTelegramLink`. После редактирования ссылка обновляется. Посетитель подтверждает отправку в Telegram. Копирование остаётся запасным способом и для MAX.

Серверной отправки нет; бот и его серверный код в этот репозиторий не входят. Данные не сохраняются кодом сайта. При переходе текст передаётся Telegram в URL; это описано в privacy.html.

Проверки перед публикацией: синтаксис встроенных скриптов, отсутствие повторных ID и битых якорей, передача полного текста в ссылку и в openTelegramLink. Проверку реального черновика на телефоне нужно выполнить отдельно.

# DEPLOY — chaika-bot.ru

Сайт состоит из двух частей: статические файлы на хостинге Рег.ру и сервис форм на Amvera.

## 1. Сайт (статика)

- **Где лежит:** хостинг Рег.ру, тариф «Хост-Лайт», сервер server277.hosting.red.ru, корень сайта chaika-bot.ru. Точный путь к папке сайта смотреть в файловом менеджере панели хостинга.
- **Что лежит:** index.html, privacy.html, offer.html, consent.html, premium.css, assets/. Папки preview-natalia-k7x2 и cloudflare/ на хостинг не заливать.
- **Выкладка:** взять main из GitHub (chajjka93-source/mini-app), залить файлы в корень сайта через файловый менеджер Рег.ру (архивом) или по FTP (логин и пароль в «Ключи и данные»).
- **Перезапуск:** не нужен, это статика. После заливки обновить страницу через Ctrl+F5.
- **Логи:** панель Рег.ру → хостинг → статистика и журналы доступа и ошибок сайта (точное название раздела зависит от панели).
- **Проверка:** https://chaika-bot.ru открывается, http переходит на https, тестовая заявка из формы доходит в Telegram.

## 2. Формы (form-service)

- **Где стоит:** Amvera, Москва-1, проект form-service, адрес https://form-service-chajjka.msk1.amvera.tech. Код: chajjka93-source/form-service (ветка main).
- **Запуск:** Node 22, команда `npm run start`, порт 3000 (amvera.yml). Секреты BOT_TOKEN и CHAT_ID заданы в настройках проекта Amvera, необязательная SITE_ORIGINS — адреса сайта через запятую (должен быть https://chaika-bot.ru).
- **Деплой:** изменения кода в репозитории, затем пересборка проекта в Amvera.
- **Перезапуск:** в кабинете Amvera → проект form-service → «Перезапустить» (или «Пересобрать», если менялся код).
- **Логи:** кабинет Amvera → проект form-service → «Логи» (запуск и ошибки приложения).

## Если не работают формы

1. Открыть адрес form-service в браузере: сервис должен отвечать.
2. Посмотреть логи в Amvera.
3. Проверить, что в SITE_ORIGINS указан https://chaika-bot.ru и что бот запущен командой /start.
